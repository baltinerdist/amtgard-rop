# Ambulant

**Available to:** Bard 5, Druid 5, Healer 5, Wizard 5

**Type:** Meta-Magic

**School:** Neutral

**Incantation:** "Ambulant"

**Effect:** The next Enchantment, Magic Ball, or Verbal may be cast while moving.

**Note:** Using Ambulant allows both the target indication and Ambulant to be said while moving, but not other Meta-Magics.
